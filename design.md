# Darco Design System

## Brand
**Name:** Darco — Instant Grocery Delivery
**Tagline:** Fresh. Fast. At your door.

## Colors
- Primary: `#16a34a` (green-600) — main brand, CTAs, active states
- Primary Light: `#dcfce7` (green-100) — backgrounds, tags
- Primary Dark: `#14532d` (green-900) — headings, dark mode
- Accent: `#f97316` (orange-500) — promo badges, flash sales, highlights
- Accent Light: `#fff7ed` (orange-50)
- Background: `#f9fafb` (gray-50)
- Surface: `#ffffff`
- Border: `#e5e7eb` (gray-200)
- Text Primary: `#111827` (gray-900)
- Text Secondary: `#6b7280` (gray-500)
- Text Muted: `#9ca3af` (gray-400)
- Success: `#16a34a`
- Warning: `#f59e0b`
- Error: `#ef4444`

## Typography
- **Font:** Poppins (Google Fonts)
- Display: 700, 2.5rem–4rem
- Heading: 600–700, 1.25rem–2rem
- Body: 400, 0.875rem–1rem
- Caption: 400, 0.75rem
- Line height: 1.5–1.7

## Spacing
- Base unit: 4px
- Section padding: 64px top/bottom
- Card padding: 16–24px
- Gap: 12–24px

## Components
- **Cards:** white bg, subtle shadow (`shadow-sm`), 16px radius, hover lift (`hover:-translate-y-0.5`)
- **Buttons:** Primary = green filled, rounded-full, font-semibold. Secondary = white + green border. Destructive = red.
- **Badges:** rounded-full, small, colored bg
- **Category circles:** 64px circle image + label below
- **Product cards:** image top, name, price, add-to-cart button
- **Promo banners:** green gradient, white text, organic shapes

## Layout
- Max width: 1280px centered
- Sidebar nav on desktop (admin/rider)
- Bottom tab nav on mobile
- Top navbar on web with search bar centered

## Motions
- Page load: fade + slide up (staggered cards)
- Cart item: slide in from right
- Add to cart: scale pop
- Rider dot: smooth CSS translate animation

## Mobile
- Bottom tab bar: Home, Categories, Cart, Orders, Profile
- Cards: full width, 8px radius, soft shadow
- Green header bars
- Floating add-to-cart button

## Inspiration
- Clean product grid with category circles (as in reference image)
- Promo banner with discount callouts
- Stats bar showing speed/delivery metrics
- Bottom sticky cart summary
